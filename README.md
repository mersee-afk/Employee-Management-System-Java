# Employee Management System

**Language:** Java  
**Type:** Console-based application  
**Level:** Beginner / Fresher Project  

## Description
A simple Employee Management System (EMS) that allows adding, viewing, updating, and deleting employee records.  
Data is saved locally in a file (`employees.txt`) so that records persist between program runs.

## Features
- Add new employee
- View all employees
- Search employee by ID
- Update employee details
- Delete employee
- Exit program

## Technologies Used
- Java 17+
- Object-Oriented Programming (OOP)
- File Handling for data persistence
